# Víctor Benito | Portfolio Personal

¡Bienvenido a mi portfolio personal como Desarrollador Web! 

## Sobre el proyecto

Este proyecto es una carta de presentación de mi experiencia, proyectos y habilidades tecnológicas. Ha sido desarrollado con un enfoque especial en el diseño, la interactividad y la limpieza del código.

## Características

- 🎨 **Diseño Moderno**: Paleta de colores oscuros con acentos *cyan* vibrantes. Efecto *Glassmorphism* (cristal ahumado) implementado en las tarjetas y la barra de navegación.
- 📱 **Responsive Design**: Completamente adaptable a teléfonos móviles, tablets y monitores grandes.
- ✨ **Animaciones**: Uso avanzado de `IntersectionObserver` de JavaScript para revelar los elementos suavemente a medida que el usuario hace scroll hacia abajo.
- 🚀 **Tecnologías Core**: Uso exclusivo de tecnologías nativas y ligeras: HTML5 semántico, CSS3 sin frameworks pesados y Vanilla JavaScript.

## Estructura de Archivos

La estructura del código busca la máxima escalabilidad y orden:
- `/assets` - Recursos estáticos organizados (`/img`, `/icons`, `/video`, `/docs`).
- `/css` - Hoja de estilos principales (`style.css`).
- `/js` - Lógica visual, menús y scroll properties (`main.js`).

## Cómo verlo en local

Para previsualizar el portfolio, simplemente navega por los archivos y abre `index.html` en tu navegador web de preferencia. No es necesario compilar nada ni abrir servidores especiales (aunque es recomendable abrir en LiveServer de estar usando VSCode).
